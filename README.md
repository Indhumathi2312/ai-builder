# AI Web App Builder — Next.js Migration

This repository contains the production-ready Next.js + TypeScript + Tailwind CSS + Framer Motion migration of the AI Web App Builder website (`ai-builder.html`).

## Tech Stack
- **Framework**: Next.js 14 (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS & Vanilla CSS Design Tokens
- **Animations**: Framer Motion
- **Static Export**: Next.js `output: 'export'`

## Getting Started

### Installation
```bash
npm install
```

### Development
```bash
npm run dev
```

### Production Build & Linting
```bash
npm run lint
npm run build
```

The build process generates the production-ready static export output in the `out/` directory.
